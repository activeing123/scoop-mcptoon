# scoop-mcptoon

Scoop bucket for [mcptoon](https://github.com/activeing123/mcptoon) - a zero-dependency
MCP gateway CLI that keeps tool and skill schemas out of your context window.

## Install

```powershell
scoop bucket add mcptoon https://github.com/activeing123/scoop-mcptoon
scoop install mcptoon
```

## Update

```powershell
scoop update mcptoon
```

The manifest self-updates: `checkver` follows the GitHub releases of
`activeing123/mcptoon`, and `autoupdate` rewrites the download URL per version.
